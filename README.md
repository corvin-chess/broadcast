<p align="center"><img src="https://readme-typing-svg.demolab.com?font=IBM+Plex+Mono&weight=700&size=18&color=8FA3D9&center=true&vCenter=true&width=420&height=40&duration=1&pause=1000000&letterSpacing=6px&lines=OVERVIEW" alt="Overview" /></p>

Planned Rust service to ingest live PGN sources from over-the-board events and publish move streams to [server](https://github.com/corvin-chess/server) spectator channels. Depends on [chess-core](https://github.com/corvin-chess/chess-core) for rules and position validation. No PGN ingest or relay pipeline is in this repository yet.
